# magic-book-translator

Agent Skill for translating English close-up and card magic instructional books (PDF) into faithful Chinese Word (`.docx`) and PDF (`.pdf`) editions with 1-to-1 pagination, cleaned white-background illustrations, standard magic terminology, native Word outline navigation, and clickable TOC bookmarks.

## Install in OpenAI Codex

1. Copy or symlink the `magic-book-translator` folder into `$CODEX_HOME/skills/` (default: `~/.codex/skills/magic-book-translator/`), ensuring `SKILL.md` is located at:
   `~/.codex/skills/magic-book-translator/SKILL.md`
2. Restart Codex to load the new skill.
